# External Live Data Sources & Geospatial Ingestion Specification

**Project:** GeoAI Hackathon 2026 (CSRE, IIT Bombay)  
**Standard:** Open Data Commons / Creative Commons / Open Access APIs with Zero Paid Dependency

## 1. Provider Registry Overview

The GeoAI backend integrates five free, open-access providers to ground all recommendations in verifiable meteorological and geographic evidence:

| Provider | Service Role | License | Attribution Statement | Endpoint |
| :--- | :--- | :--- | :--- | :--- |
| **OpenStreetMap Nominatim** | Forward & Reverse Geocoding | Open Data Commons Open Database License (ODbL) 1.0 | `© OpenStreetMap contributors` | `https://nominatim.openstreetmap.org` |
| **OpenStreetMap Overpass API** | Nearby Venue & Feature Discovery | Open Data Commons Open Database License (ODbL) 1.0 | `© OpenStreetMap contributors` | `https://overpass-api.de/api/interpreter` |
| **Open-Meteo Weather Forecast API** | Numerical Weather Prediction (Hourly) | Creative Commons Attribution 4.0 International (CC BY 4.0) | `Weather data by Open-Meteo.com` | `https://api.open-meteo.com/v1/forecast` |
| **Open-Meteo Air Quality API** | Atmospheric Composition & AQI | Creative Commons Attribution 4.0 International (CC BY 4.0) | `Air quality data by Open-Meteo.com / CAMS / NOAA` | `https://air-quality-api.open-meteo.com/v1/air-quality` |
| **Project OSRM** | Road Network Distance & Static Time | BSD 2-Clause License & OpenStreetMap (ODbL) | `Routing powered by OSRM and © OpenStreetMap contributors` | `https://router.project-osrm.org` |

## 2. Ingestion Modules & Operational Policies

### A. Geocoding & Location Resolution (`app/services/geocoding.py`)
- **Engine:** OpenStreetMap Nominatim v2 Search & Reverse API.
- **Compliance Policy:**
  - Identifies client via descriptive User-Agent: `GeoAI-Hackathon-2026-CSRE-IITB/1.0`.
  - Enforces minimum 1.0-second delay between consecutive calls (`_rate_limit_wait()`).
  - Implements in-memory TTL caching (default 15 minutes) to eliminate redundant external requests.
- **Graceful Degradation:** If Nominatim returns no results, the system marks coordinates as missing rather than fabricating a location.

### B. Nearby Outdoor Venues & Parks (`app/services/overpass.py`)
- **Engine:** OpenStreetMap Overpass QL Interpreter.
- **Queried Tags:**
  - `leisure=park`, `leisure=nature_reserve`, `leisure=pitch`, `leisure=track`, `leisure=golf_course`
  - `highway=path`, `highway=cycleway`, `route=hiking`, `route=bicycle`
  - `tourism=viewpoint`, `tourism=picnic_site`, `amenity=bench`
- **Output:** Top-ranked candidate venues scored by distance and activity tag affinity.

### C. Live Meteorological Forecasts (`app/services/weather.py`)
- **Engine:** Open-Meteo Global Numerical Weather Prediction model ensemble.
- **Hourly Ingested Variables:**
  - `temperature_2m` (°C) and `apparent_temperature` (°C)
  - `relative_humidity_2m` (%)
  - `precipitation_probability` (%) and `precipitation` (mm)
  - `weathercode` (WMO interpretation codes 0 to 99)
  - `windspeed_10m` (km/h), `windgusts_10m` (km/h), and `winddirection_10m` (degrees)
  - `uv_index` (Global Solar UV Index scale)
- **Constraint:** Missing values are recorded as `None`; values are never synthetically invented.

### D. Atmospheric Air Quality (`app/services/air_quality.py`)
- **Engine:** Open-Meteo Air Quality API powered by Copernicus Atmosphere Monitoring Service (CAMS) and NOAA GFS-Aerosol.
- **Strict Scale Differentiation:**
  - **US EPA AQI (0–500 scale):** 0–50 (Good), 51–100 (Moderate), 101–150 (Sensitive Groups), 151–200 (Unhealthy), 201–300 (Very Unhealthy), >300 (Hazardous).
  - **European Common Air Quality Index (1–5 scale):** Very Good (1) to Very Poor (5).
  - **Particulate Matter:** PM2.5 ($\mu\text{g/m}^3$) and PM10 ($\mu\text{g/m}^3$).
  - **Gases:** Ozone ($O_3$), Nitrogen Dioxide ($NO_2$), Carbon Monoxide ($CO$).

### E. Road Routing & Distance (`app/services/routing.py`)
- **Engine:** Project OSRM public demo server.
- **Critical Disclaimer:** OSRM calculates static topological distance along mapped OpenStreetMap road networks using default speed limits. **It does not provide live dynamic vehicular traffic congestion.** The system explicitly notes this limitation in all routing responses.

### F. Solar Geometry & Daylight Status (`app/services/sun_time.py`)
- **Engine:** Deterministic NOAA Solar Geometry calculation.
- **Outputs:** UTC sunrise, sunset, solar noon, daylight duration, and day/night status.

## 3. Data Attribution Compliance

All API responses generated by `POST /recommend` embed the explicit attribution metadata block required by OpenStreetMap and Open-Meteo:
```json
{
  "provider": "OpenStreetMap Nominatim",
  "service_type": "Geocoding",
  "retrieval_timestamp": "2026-10-23T15:58:39.734125+00:00",
  "attribution": "© OpenStreetMap contributors"
}
```
